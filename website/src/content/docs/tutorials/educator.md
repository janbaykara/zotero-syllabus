Use Zotero Syllabus to maintain a living reading list in Zotero, then export or publish a clean copy for students.

## 1. Create a syllabus collection

1. Create a Zotero collection for the module (or reuse an existing one).
2. Add the readings (and any handouts) as items.
3. Select the collection and click **Turn into Syllabus**.

![Syllabus classes](../../../assets/images/classes.png)

## 2. Add classes and assign readings

- **Add Class** for each week or session (rename the word in Syllabus **Settings** — week / class / session).
- Drag items onto a class, or right-click → **Assign to a class**.
- Put handouts under **Course Information** (or your top priority) so they stay at the top.

Unassigned items remain under **Further reading**.

Full detail: [Syllabus how-to](/zotero-syllabus/how-to/syllabus/).

## 3. Priorities and reading instructions

In the item pane **Reading assignments** section (or via right-click):

- Set **priority** (Essential, Recommended, Optional, Course Information — editable in Settings).
- Add a short **instruction** (“read chapters 1–3”, “skim for method”).
- Optionally mark items **done** for your own tracking.

![Editing assignments](../../../assets/images/editing.png)

## 4. Optional: class subcollections

In Syllabus **Settings**, **Class subcollections** creates a child folder per class and keeps membership in sync. Leave this **off** unless you want folder mirrors — do not edit those folders by hand. See [Auto-managed folders](/zotero-syllabus/concepts/auto-managed-folders/).

## 5. Print, save, or publish

Use the printer icon on the syllabus header:

- **Save as PDF, Word, Markdown, or HTML** — include a bibliography if that option is on.
- **Publish online** — a public URL (HTML + attachments). Only publish materials you have the right to share.

See [Print, export, and publish](/zotero-syllabus/how-to/print-export-publish/).

## 6. Share the workflow with students

Point students at [Getting started](/zotero-syllabus/getting-started/) and the [student tutorial](/zotero-syllabus/tutorials/student/). If your institution uses Talis, Leganto, or similar, they can [import the list](/zotero-syllabus/how-to/import-reading-lists/) themselves into their own library.

## Tips

- Use **Lock** before projecting or demoing so the list is not edited by accident.
- Standalone notes can be [class notes](/zotero-syllabus/concepts/class-notes/) — private to the syllabus, not exported on publish/print.
- Library-wide default priorities live in **Preferences → Zotero Syllabus**; per-syllabus overrides live in Syllabus Settings.
