---
title: Class notes
description: Private standalone notes assigned to a class on a syllabus.
---

Standalone notes in a syllabus collection can be assigned to a class like any reading. They use the same Syllabus cards and ordering, with a fixed yellow **Class Note** label instead of a priority.

## Where they appear

- In **Syllabus** view, under their class (or with unassigned / priority-only items at the top when not assigned)

## Where they do not appear

Class notes stay **private**. They do not appear on:

- Reading Schedule
- Gallery
- Annotation Feed
- Class folders
- Print
- Publish

Use them for session plans, teaching reminders, or personal prompts that should not go out with the student-facing list.
