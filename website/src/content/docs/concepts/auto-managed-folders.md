---
title: Auto-managed folders
description: Class subcollections and the Reading Schedule collection — mirrors you should not edit by hand.
---

Some optional features create Zotero collections that the plugin **owns**. Membership is kept in sync automatically. Treat them as mirrors, not as folders you curate.

## Class subcollections

Off by default. In Syllabus **Settings**, turn on **Class subcollections** to create a child folder per class. The plugin adds and removes items to match class assignments.

**Do not** add or remove items in those folders by hand. Edit assignments in Syllabus view (or via Assign to a class) instead.

## Reading Schedule collection

**Preferences → Generate a “Reading Schedule” collection** builds a folder tree for upcoming dates, with a `Pinned` child for pinned items.

Again: do not edit membership by hand. Turn the preference off to remove that collection; your syllabus items stay where they were.

## Why leave them off?

Most students and educators never need folder mirrors. Syllabus view, Reading Schedule tab, and Home already surface the same information without extra sidebar noise.
