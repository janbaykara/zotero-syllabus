---
title: Personal reading order
description: Your own flat reading sequence for a collection, separate from class structure.
---

**Personal reading order** is a flat list of item keys you want to read in — stored separately from syllabus class structure in a note titled **Personal reading order -** your collection name. Use it when class order is not how you plan to tackle the pile. The same note can also hold an optional **Gallery description** for the collection (shown under the Gallery title and on published reading-list pages).

## What it affects

- **Pinned stacks / Next up** — when the order is non-empty, next-up and pinned collection stacks prefer personal order instead of syllabus class order.
- **Gallery** — choose sort **Personal Reading Order** for a flat list (prioritised items, then unprioritised items). Group-by is ignored in that mode.
- **Syllabus tab** — stays class-structured; personal order does not rearrange classes.

## Marking done

Reading done status for this flow is tied to personal reading order: item checkboxes, per-assignment checkboxes on Syllabus, and **class-level** done (including migration from older flags on the Syllabus note). Item done keys are stored in the order you tick them. Gallery’s Done section shows that list with the most recently finished item first. Dragging an item out of Done into the prioritised or unprioritised list clears its done tick. Marking the current **Next up** reading done advances the pin.

## How to use it

From item context menus on a collection, use **Add to collection reading order** / **Remove from collection reading order** (wording may follow your Zotero language). Adding places items at the head of the personal order; removing drops them from it. Reorder via Gallery’s **Reading order** sort — the ordered section is headed with a count of prioritised items, and drag into the **unprioritised items** zone (always shown, even when empty) to take items out of the list.

For day-to-day studying, combine personal order with [pinning](/zotero-syllabus/how-to/pinning/) the collection so Home always shows the right next item.
