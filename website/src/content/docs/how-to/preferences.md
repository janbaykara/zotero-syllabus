---
title: Preferences
description: Global Zotero Syllabus settings for views, density, Gallery defaults, and copy options.
---

Open **Preferences → Zotero Syllabus** (Zotero Settings) for options that apply across the library.

## Views

Turn each surface on or off: Syllabus, Gallery, Home, Reading Schedule, Annotation Feed.

## Display defaults

- Default **density** for card layouts
- Default **Gallery** layout (used when a collection has not set its own)
- Quote-copy options shared with Annotation Feed (Markdown blockquotes, Pandoc cite keys)

## Reading Schedule collection

Optionally generate an auto-managed **Reading Schedule** collection tree. See [Auto-managed folders](/zotero-syllabus/concepts/auto-managed-folders/).

## Per-syllabus overrides

Nomenclature (week / class / session), priorities, bibliography, and class subcollections live on the syllabus header **Settings**, not only in Preferences.

For a compact checklist, see [Preferences checklist](/zotero-syllabus/reference/preferences-checklist/).
