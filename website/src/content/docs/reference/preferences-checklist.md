## Preferences → Zotero Syllabus

| Area | What to check |
| --- | --- |
| **Views** | Syllabus, Gallery, Home, Reading Schedule, Annotation Feed on/off |
| **Display** | Default density; default Gallery layout |
| **Copy** | Markdown blockquote prefix; Pandoc cite keys on copy from feed |
| **Reading Schedule collection** | Generate auto-managed folder tree (optional) |

## Per collection / syllabus

| Control | Where |
| --- | --- |
| Gallery view / sort / group | Gallery header `(view / sort / group)`; **Save as default** globe |
| Syllabus nomenclature, priorities, bibliography, class subcollections | Syllabus header **Settings** |
| Lock / Print / Pin | Syllabus header |
| Home shelf visibility and order | Home **Configure** |
| Shelf layout | Per-shelf **Configure** |

## Zotero itself

| Setting | Effect on the plugin |
| --- | --- |
| Language | Plugin UI language |
| Show Items from Subcollections | Gallery includes nested items |
| Zotero Connector | Required for [reading-list import](/zotero-syllabus/how-to/import-reading-lists/) |
