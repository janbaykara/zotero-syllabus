Zotero Syllabus turns your collections into course reading lists: order items by class, browse covers in Gallery, keep a Home of what to open next, follow due dates on Reading Schedule, and review highlights in Annotation Feed.

## Install

1. [Download the extension file (](https://github.com/janbaykara/zotero-syllabus/releases/latest/download/zotero-syllabus.xpi)`.xpi`[)](https://github.com/janbaykara/zotero-syllabus/releases/latest/download/zotero-syllabus.xpi).
2. In the Zotero menu bar, go to **Tools → Plugins** (or **Add-ons**).
3. Click the gear icon in the top right and select **Install Plugin From File…**.
4. Select the downloaded `.xpi` file.
5. Ensure auto-updating is enabled for this add-on.
6. Restart Zotero.

:::tip[Zotero version]  
For best results, use [Zotero 8, 9, or 10](https://www.zotero.org/download/). Zotero 7 works but has some minor styling issues.  
:::

## Enable the views you need

Open **Preferences → Zotero Syllabus → Views** and turn each surface on or off:


| Surface              | Where it appears                                         |
| -------------------- | -------------------------------------------------------- |
| **Syllabus**         | On a collection — toolbar **Table / Gallery / Syllabus** |
| **Gallery**          | Same collection toolbar                                  |
| **Home**             | Library root — **Table / Home**                          |
| **Reading Schedule** | Its own tab (toolbar or from Home)                       |
| **Annotation Feed**  | Its own tab (toolbar or from Home)                       |




## Open the docs anytime

In Zotero: **Help → Zotero Syllabus Documentation** opens this site. For a short walkthrough in the app, use **Help → Open Zotero Syllabus User Guide**.

## Language

The plugin UI follows **Zotero’s language** (Settings → General → Language). Besides English and Simplified Chinese, that includes Brazilian and European Portuguese, German, Spanish, French, Italian, Japanese, Korean, Traditional Chinese, Dutch, Polish, Turkish, Arabic, Indonesian, Russian, Ukrainian, and Vietnamese.
